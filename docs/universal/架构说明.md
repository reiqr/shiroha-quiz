# 架构说明

## 项目布局

项目在同一仓库维护 Web 和 Android 原生两条公开使用线。两端共享题库、备份格式和可对齐的业务规则，解析与答题逻辑各自实现，并没有共同依赖的 `packages/` 源码层。

| 路径 | 职责 |
| --- | --- |
| `apps/web/` | HTML、CSS、JavaScript 单页应用；提供桌面导入、题库管理、刷题和备份。可本地启动，也可部署为静态网页。 |
| `apps/android/app/src/native/` | Kotlin + Jetpack Compose + Material3；包含原生页面、导入解析、答题、数据状态、AI、MinerU 与 WebDAV。 |
| `apps/android/app/src/katex/` | Android 默认公式显示实现，包含本地 KaTeX 页面、脚本和字体。 |
| `apps/android/app/src/ratex/`、`lite/` | 开发用 RaTeX 对照及纯文本构建。对照包专用题库在 `latexComparison/`。 |
| `apps/android/app/src/web/` | 保留的历史 WebView 壳，不随公开 Web 版自动同步。 |
| `docs/`、`test/`、`assets/` | 使用与工程文档、专项测试及宣传素材。 |

## 运行与发布

- **Android 原生**：`native` flavor 的正式包名是 `com.reqir.shirohaquiz`。主分支的默认正式构建只打包 KaTeX；附加对照参数的测试包使用独立包名，不是发布附件。历史 `web` flavor 的包名是 `com.yiqiu.shirohaquiz`。
- **Web**：在线版从 `main` 的 `apps/web/` 部署到 GitHub Pages；下载版 Web ZIP 和 Android APK 则由 [Releases](https://github.com/reiqr/shiroha-quiz/releases) 单独交付。
- **数据边界**：答题、题库和本地备份保存于各自客户端。本地导入不需要把题库发到项目服务器；AI、MinerU 和 WebDAV 仅在启用并使用相应服务时进行网络请求。
- **跨端互通**：普通题库 JSON、完整备份及含图片 ZIP 的适用入口和限制，以[导入格式支持说明](../题库导入格式支持说明/Shiroha_Quiz_题库导入格式支持说明.md)为准。

## 分支策略

| 分支 | 用途 | 推送 |
| --- | --- | --- |
| `main` | 公开主线；已合入源码与 Release 附件需分别确认 | 推送到 `origin` |
| `content-admin` | 后台化功能（server / admin） | 仅本地，不推送也不混入公开版 |
