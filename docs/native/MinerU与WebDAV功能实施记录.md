# Shiroha Quiz 原生 MinerU 与 WebDAV 功能实施记录

更新日期：2026-09-14

开发版本：`0.9.9`（原生独立版本，随 v2.8.7-beta 统一发布）

## 功能入口

- 文档识别：我的 → 文档识别；导入页 → 在线解析 PDF。
- 云端备份：我的 → 数据管理 → 云端备份。

## MinerU 文档识别

免费模式免 Token，当前按 10 MB、20 页做提交前检查。精准模式使用用户自己的 Token，支持选择 VLM / Pipeline，配置页码、语言、OCR、表格和公式识别。服务限制以 [MinerU 官方说明](https://mineru.net/apiManage/docs) 为准。

上传前确认原始 PDF 将发送至 MinerU。上传显示实际进度；任务支持暂停、继续查询和本地任务持久化。离开页面后可通过全局任务提示回到任务页。服务器任务不能由“暂停查询”取消。

免费模式读取 Markdown。精准模式读取结果 ZIP 的 `full.md` 和 `content_list.json`，提取图片并转为现有 `[[SHIROHA_IMAGE:img_0001]]` 标记；正文缺失时才使用结构化内容作为回退来源。高级设置可选择附加 Word / HTML / LaTeX 输出，结果页可保存完整 ZIP 或免费模式 Markdown。

图片默认按正文位置绑定，可人工排除、排序、指定题目和合并相邻碎图。指定题目填的是导入预览的列表序号，从 1 开始；不是原文题号，避免分卷重复题号产生歧义。图片不会自动拼接。

进入题库导入前仍需检查文字和图片，之后使用现有解析器与沉浸核对流程。原始 PDF、识别结果和临时图片保存在不参与系统备份的目录中；确认导入的图片复制到正式题目资源目录，临时任务清理不会删掉已保存题目的图片。

## WebDAV 云端备份

只支持 HTTPS、Basic Auth / 应用专用密码，不忽略证书错误。默认远程目录为 `/ShirohaQuiz/Backups/`。首次使用先保存配置、测试连接，再主动创建目录。

每次上传创建唯一名称的新 ZIP，先上传 `.uploading` 文件，通过大小和 SHA-256 校验后再 MOVE 到正式名称，不覆盖旧备份。附加元数据文件用于展示时间、来源版本等信息；元数据写入失败不删除已完成的备份。

远程列表提供恢复、下载到本地和删除。下载执行完整性校验，删除需要确认。无法取得完整校验信息的旧文件会明确提示，不能作为已经验证的备份直接恢复。

恢复方式：

1. 导入为副本：保留当前数据，按现有追加导入规则重映射题库 ID。
2. 覆盖恢复：预览数量并二次确认，先生成本地安全备份，再替换题库、错题、收藏、斩题和学习记录；保留外观、AI、OCR 和 WebDAV 配置。

覆盖失败会回滚；应用中断时，未完成恢复日志在下次初始化时处理。安全备份保留最近三组，旧题目图片不在恢复事务中删除。

## 自动备份

默认关闭，可设每天或每周，限制 Wi-Fi / 充电条件，通过 WorkManager 唯一任务执行。自动备份要求密码已经加密保存在本机，执行时间由 Android 调度，不承诺固定时刻。

自动删除旧备份默认关闭，需要单独确认。开启后只在本次备份上传成功后清理超出保留数量的 Android 备份，可选择保留 5 / 10 / 20 份。建议先验证自己的服务能够完成手动上传、下载与恢复。

## 数据与密钥边界

MinerU Token 与 WebDAV 密码使用独立逻辑密钥和 Android Keystore 别名，密文写入 `noBackupFilesDir`。它们不存入题库仓库、不进入题库备份，也不会随云端恢复覆盖。

WebDAV 只备份已保存的数据，未确认的 OCR 草稿、原始 PDF 和临时 AI 对话不上传。

完整 JSON 的读取限制与图片资源单项限制分开：完整 JSON / 云端文件最多 150 MiB；ZIP 解压总量保持 100 MiB，图片等单项保持 20 MiB，最多 1000 个条目。ZIP 路径、重复条目、CRC、大小、版本和资源引用均做验证。

## 验证说明

新增测试分别覆盖 Markdown 保真、图片标记与人工归属、WebDAV 网络操作，以及隔离的覆盖恢复/回滚。云端恢复测试使用独立偏好和文件目录，不操作用户真实题库。

本轮新增 27 项定向单元测试全部通过，其中云端恢复测试包含 14 个隔离场景。原生 Kotlin 编译和 Android 恢复测试包构建通过；UTF-8 与改动空白检查通过。

编译与模拟测试通过不能替代实际设备、真实 PDF 和服务商账户的验收；免费限频、Token 权限、服务商 MOVE 支持和大文件体验仍需实测。目前没有连接测试设备，也未使用真实 MinerU Token 或 WebDAV 账户。

本地定向测试可在 `apps/android` 目录执行：

```powershell
.\gradlew.bat :app:testNativeDebugUnitTest --tests 'com.yiqiu.shirohaquiz.document.*' --tests 'com.yiqiu.shirohaquiz.sync.webdav.*' --tests 'com.yiqiu.shirohaquiz.state.CloudRestoreJvmTest'
```

首次执行需要下载依赖。已有依赖缓存时可加 `--offline`。测试依赖仅加在原生测试配置中，不进入正式安装包。

未修改的旧标准解析冒烟测试中，规则顺序断言尚未包含已有的 `compact_answer_line`，会报一个与本轮更新无关的失败；解析器和该旧样例均未修改。本轮新增测试应单独筛选执行，不能把旧断言失败当成本轮功能失败。
