# Shiroha Quiz WebDAV 云备份使用指南

> 本文面向普通使用者，说明如何把 Shiroha Quiz 的题库数据备份到自己的 WebDAV 云盘，以及如何从云端恢复。

---

## 一、这个功能能做什么

把题库数据备份到**你自己的 WebDAV 云盘**，不再依赖手动导出文件。

- 手动上传完整备份
- 查看云端的历史备份列表
- 从云端恢复数据（合并导入或覆盖恢复）
- 原生 Android 版还支持按天 / 周自动备份

WebDAV 只负责「传文件」：上传的内容仍然是 Shiroha Quiz 的完整备份包，和导出到本地的备份格式完全一致。因此云备份和本地备份可以互相替代，也可以互相恢复。

---

## 二、使用前提

### 需要一个 WebDAV 服务

WebDAV 是一种通用的网盘协议，常见的支持方包括：

- 坚果云
- Nextcloud / ownCloud
- 群晖（Synology）NAS
- 阿里云盘、腾讯云 COS 等的 WebDAV 网关
- 自建 WebDAV 服务

具体地址和账号请以你的服务商说明为准。

### 地址协议与浏览器限制

- **原生 Android 版**：只支持 `https://`，HTTP 地址会被拒绝。
- **Web 版**：接受完整的 `http://` 或 `https://` 地址，建议使用 HTTPS。HTTP 会明文传输账号凭据和备份数据。
- HTTPS 页面访问 HTTP WebDAV 时，由浏览器决定是否允许请求。应用会尝试发起请求；如果浏览器已允许且服务端跨域配置正确，可以正常连接。
- 请求失败后，连接诊断会提示可能存在混合内容拦截，同时保留网络或 CORS 问题的可能性；仅凭请求失败无法确定具体原因。允许不安全内容也不能替代服务端 CORS 配置。

### 建议使用应用专用密码

如果服务商支持「应用专用密码」或「第三方应用授权」，请优先使用它，不要直接使用主账号密码。开启了两步验证的账号通常必须这么做。

## 三、Web 端配置

入口：**设置/导出 → WebDAV 云备份**

| 字段          | 说明                                    | 示例                                    |
| ----------- | ------------------------------------- | ------------------------------------- |
| WebDAV 地址   | 服务商提供的 WebDAV 根地址，不要带查询参数             | `https://dav.jianguoyun.com/dav/`     |
| 远端目录       | 备份存放的目录，不存在时会尝试自动创建                   | `ShirohaQuiz/Web`                     |
| 用户名         | WebDAV 账号                             | `your@email.com`                      |
| 密码          | 密码或应用专用密码                             | —                                     |

**「记住密码」选项：**

- 不勾选（默认）：密码只保留在当前标签页，关闭标签页后需要重新输入。
- 勾选：密码保存在本浏览器本地，下次打开自动填入。

**操作顺序：**

1. 填写地址、目录、账号和密码。
2. 点 **保存配置**。
3. 点 **测试连接**，确认能访问 WebDAV 根地址。
4. 点 **上传当前完整备份** 开始备份。

> **关于跨域（CORS）**：浏览器直连 WebDAV 时，服务端需要允许当前页面的来源，并放行 `OPTIONS`、`PROPFIND`、`MKCOL`、`GET`、`PUT` 方法及 `Authorization`、`Content-Type`、`Depth` 请求头。如果服务端未配置，连接会失败。
>
> 失败时可以展开 **连接诊断**，里面会给出错误分类和处理建议，也可以一键复制（不含密码）用于排查。

## 四、原生端配置

入口：**我的 → 数据管理 → 云端备份**

配置项与 Web 端一致。区别在于：

- 原生端通过系统网络栈直接请求，**不受浏览器跨域限制**。
- 密码使用 Android Keystore 加密后保存在本机，不参与任何备份。
- 默认远程目录为 `/ShirohaQuiz/Backups/`。

**首次使用建议按此顺序：**

1. 保存配置。
2. 测试连接。
3. 手动创建一次目录（部分服务端不会自动创建多级目录）。
4. 上传一次备份，确认云端能看到文件。

> 建议先完整验证一次「手动上传 → 下载 → 恢复」流程，再考虑开启自动备份。

## 五、上传与恢复

### 上传备份

- Web 端：点 **上传当前完整备份**。
- 原生端：在云端备份页点上传。

上传时会创建一个带时间戳的唯一文件名，**不会覆盖云端已有的旧备份**。原生端还会先上传临时文件，校验大小与 SHA-256 通过后才转为正式文件，避免半截文件被误当成有效备份。

### 查看与下载

点 **刷新远程备份** 可读取云端列表。原生端的列表支持：

- **恢复**：把该备份恢复到当前设备
- **下载到本地**：先保存到手机，稍后再处理
- **删除**：删除云端文件（需要确认）

### 恢复方式

| 方式                               | 含义                   | 适合场景        |
| -------------------------------- | -------------------- | ------------- |
| 合并导入（原生端显示为「导入为副本」）              | 保留当前数据，把备份中的题库追加进来   | 想合并另一台设备的数据 |
| 覆盖恢复                             | 用备份替换当前题库、错题、收藏和学习记录 | 换设备、数据损坏后还原 |

**覆盖恢复的安全机制：**

- 恢复前会先展示备份中的题库数量和题目数量，需要二次确认。
- 执行前会先生成一份本地安全备份，万一出问题可以回退。
- 写入失败会**自动回滚**到恢复前的状态。
- 恢复只替换题库数据，**外观设置、AI 配置、OCR 配置和 WebDAV 配置会保留**。
- 本地安全备份会保留最近三组。

## 六、自动备份（仅原生 Android 版）

在原生版的云端备份页可以设置自动备份：

- **默认关闭**，需要手动开启。
- 可设每天或每周执行。
- 可限制仅在 Wi-Fi 下、或仅在充电时执行。
- 由 Android 系统调度，**不承诺在固定时刻执行**（系统可能因省电策略延后）。
- 需要密码已经加密保存在本机，否则无法自动执行。

**自动删除旧备份**同样默认关闭，需要单独确认开启。开启后可以选择保留 5 / 10 / 20 份，超过数量的旧备份会在**本次上传成功后**清理。

## 七、常见问题与处理建议

| 问题                    | 可能原因                        | 处理建议                                                    |
| --------------------- | --------------------------- | ------------------------------------------------------- |
| 测试连接就失败               | 地址错误、服务未开启 WebDAV、证书不可信      | 核对服务商提供的 WebDAV 地址，确认服务已启用                              |
| 浏览器提示网络 / CORS 失败     | 服务端未放行跨域请求                  | 在 WebDAV 服务端配置 CORS，允许应用来源和 `PROPFIND`、`MKCOL`、`PUT` 等方法 |
| 提示可能的混合内容拦截 | HTTPS 页面请求 HTTP 服务失败，也可能是网络或 CORS 问题 | 优先使用 HTTPS；若浏览器已允许该请求，继续检查服务状态、CORS 和控制台错误 |
| 返回 401 / 鉴权失败         | 密码错误，或使用了主密码而非应用专用密码        | 检查账号凭据；开启两步验证的账号通常必须使用应用专用密码                            |
| 返回 404 / 路径不存在        | WebDAV 根地址或远端目录不对           | 核对根地址；首次上传会自动创建目录，部分服务端需要手动建目录                          |
| 返回 405 / 方法不允许        | 反向代理未开放 WebDAV 方法           | 确认代理允许 `PROPFIND`、`MKCOL`、`GET`、`PUT`                   |
| 返回 413 / 上传过大         | 服务端限制单次上传大小                 | 提高服务端限制，或减少题库中的大图片                                      |
| 上传后看不到文件              | 目录填错，或列表未刷新                 | 点「刷新远程备份」重新读取                                           |
| 恢复后数据没变化              | 选成了「导入为副本」                  | 需要整体还原时请选择「覆盖恢复」                                        |

## 八、安全与隐私

- **密码不进入备份**：无论是本地导出的备份文件，还是上传到云端的备份包，都不包含 WebDAV 密码和 MinerU Token。
- **原生端加密存储**：密码使用 Android Keystore 加密，密文保存在不参与系统备份的目录中，不随云端恢复被覆盖。
- **Web 端分离存储**：默认只保留在当前标签页会话；勾选记住后才写入浏览器本地，可随时用「清除配置」删除。
- **只上传已保存的数据**：未确认的识别草稿、原始 PDF、临时 AI 对话都不在备份范围内。
- **不忽略证书错误**：客户端不会绕过 TLS 证书校验，证书不可信时会直接失败。

## 九、和本地备份怎么选

| 场景             | 建议                          |
| -------------- | --------------------------- |
| 偶尔备份、换设备前      | 用「设置/导出」导出 JSON/ZIP 即可      |
| 经常刷题、想定期留档     | 用 WebDAV 云备份，可搭配自动备份         |
| 多台设备之间同步题库     | 上传后用另一台设备「导入为副本」            |
| 数据损坏或误删，想整体还原  | 用「覆盖恢复」                     |

两种方式可以同时使用，互不冲突。
